# Project rules

- Preserve Cactus Digital Media identity and verified current contact details.
- Do not publish unsupported project outcomes, testimonials, client relationships or technology stacks.
- Keep SMTP credentials and tokens server-side; never commit .env or use VITE_ secrets.
- No fake submission successes. Fail closed when provider or abuse-control setup is missing.
- Preserve static prerendering, API routing, permanent redirects and 404 status.
- Test accessibility, mobile interactions and form failures before release.
- Keep the existing production website live until preview acceptance and explicit owner cutover approval.
- Update TASKS.md, CHANGELOG.md and docs/MEMORY.md when behavior or deployment status changes.
