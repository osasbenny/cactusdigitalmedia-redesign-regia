# Portfolio

35 website entries come from the user-supplied archive. 23 use local screenshots; 12 have a deliberately typographic card instead of a fake screenshot or remote thumbnail dependency. Four featured projects have local screenshots: AIM Glow Cosmetics, ANAIT, NG Content Concepts, Golden FM Yenagoa.

`src/data/projects.json` is the content source. Fields: slug, title, category, description, image, sourceUrl (audit provenance), liveUrl, featured, status, technologies. No technologies, outcomes, project years or detailed case-study narratives are invented. Detail routes present only the archived design and verified information. LINK_CHECKS.json records endpoint results on 2026-09-28; successful HTTP responses are not a claim about current third-party site quality.

Filters select all or featured work; search narrows titles. Add categories only when verified projects support them. Add problem, solution, gallery, year and client data when verified case-study material is available.
